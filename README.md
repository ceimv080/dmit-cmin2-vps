## 移动宽带究竟卡在哪一步

普通香港或洛杉矶 VPS 默认走 163 骨干网，晚高峰三网一起堵，延迟从 30ms 窜到 200ms 属于常态。移动用户还多两层麻烦：去程如果机房没接移动的 CMI 出口，数据可能先绕日本、新加坡再回来，延迟直接翻倍；回程走普通 163 时会被体量更大的电信流量挤占，而移动自己的国际出口带宽本来就紧张，挤到最后体验最差的那一方往往是移动用户。

商家说“移动优化”，做的就是花钱接移动的精品线路，让你的数据走专属通道。

CMI 和 CMIN2 差一个字，差的是两代产品。CMI 走移动国际出口，可能绕路，香港方向延迟 30–50ms，晚高峰有波动，价格便宜；CMIN2 是 CMI 的新一代优化，路由更直、少绕弯，香港方向可以压到 30ms 以内，晚高峰稳定性更好，价格也贵一档。判断一台机器是不是真为移动用户准备，看它回程是不是强制走 AS58807。

这里要纠正一个常见误解：洛杉矶机房离中国大陆一万公里，CMIN2 解决的是“绕路”和“拥堵”，不会把 150ms 变成 30ms。想要个位数延迟，得看香港、东京的机房，这是物理距离决定的，任何线路优化都改不了。

## 常见问题

**移动用户一定要买 CMIN2 吗？**
不一定。预算极低、只是偶尔用，普通线路也能凑合，代价是晚高峰的波动得自己扛。但只要你对“晚上打开网页转圈”这件事有意见，CMIN2 是移动侧目前能买到的最高一档线路。

**CMIN2 和 CN2 GIA 哪个好？**
看你用哪家宽带。电信用户选 CN2 GIA，移动用户选 CMIN2，联通用户两条都不算专属优化。DMIT 同价位下 EB 的流量是 Pro 的两倍，如果三网都有人用、移动占比最高，EB 更合适。

**9.99 美元那款够建站吗？**
静态站、轻量 WordPress、个人博客够用，1 核 2GB 加 1.5TB 月流量对个人站是宽裕的。跑 WooCommerce、多人协作的后台、或者数据库查询密集的程序，直接看 EB.Pocket 及以上，2GB 内存撑不住 MySQL 加 PHP 的组合。

**流量用超了会怎样？**
降速，不停机不扣费，TINY 到 STARTER 降到 4Mbps，MINI 和 MICRO 降到 8Mbps。真跑超了还能用流量重置恢复 20%，最多 2 次，具体规则见上文。

**买错了能退吗？**
3 天内且流量不超过 30GB 可以全额退，扣支付网关手续费；30 天内按剩余核算部分退。续费订单不退。所以第一周就把实际业务跑一遍，晚高峰测速也做了，别拖到第二周才想起来不合适。
